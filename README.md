# Calculadora em Java

Calculadora de console feita em Java, com operações matemáticas básicas e algumas funcionalidades extras.

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Cálculo de porcentagem
- Cálculo de IMC (Índice de Massa Corporal), com classificação do resultado
- Validação de entrada (não deixa o programa quebrar se o usuário digitar algo inválido)
- Tratamento de divisão por zero

## Tecnologias

- Java (sem dependências externas)

## Como executar

1. Compile o arquivo:
   ```
   javac Calculadora.java
   ```
2. Execute:
   ```
   java Calculadora
   ```
3. Escolha uma opção no menu e siga as instruções no terminal.

## Sobre o projeto

Projeto feito para praticar lógica de programação, estruturas de repetição/condicionais e organização de código em métodos separados por responsabilidade.
